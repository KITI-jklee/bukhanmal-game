# 산성비게임 난이도 분류 기준

> 데이터: `public/data/acidrain_pairs.json` (14,689개)
> 최종 갱신: 2026-08-19 (4자 초과 대응어 쌍 제외 포함)
> 관련 기획서: 북한말_학습게임_상세기획서.md 4-2 (산성비게임 단어 난이도 선택)
> 관련 문서: [chosung-difficulty-criteria.md](chosung-difficulty-criteria.md) (초성게임 난이도 기준)

## 분류 원칙

산성비게임은 화면에 표시되는 **북한말을 보고 남한 대응어를 입력하거나, 남한말을 보고
북한 대응어를 입력하는 방식**으로 진행된다. 따라서 초성게임과 달리 단어의 의미
자체보다는 **반대쪽 대응어를 얼마나 빠르게 연상하고 입력할 수 있는지**를 중심으로
난이도를 분류한다.

전체 대응어 쌍에 대해 아래 요소를 종합하여 `쉬움`/`보통`/`어려움` 3단계로 구분한다.
(`AcidRainPair.difficulty`의 저장값은 초성게임과 동일하게 이 세 문자열 그대로다 —
`src/lib/types.ts` 참고.)

## 1. 남북 대응어의 유사도 (가장 큰 영향)

데이터에 포함된 `similarity` 값을 기준으로 남북한 표현의 형태가 얼마나 비슷한지를
평가한다.

| 유사도 | 기본 점수 | 기준 |
|---|---:|---|
| 높음 | 1점 | 철자나 형태가 매우 비슷하여 대응어를 쉽게 연상 가능 |
| 보통 | 3점 | 일부 공통점은 있지만 바로 변환하기는 어려움 |
| 낮음 | 5점 | 형태가 크게 달라 대응어를 알고 있어야 입력 가능 |

**예시**
- `가대기군 ↔ 가대기꾼` → 형태가 거의 같아 쉬움
- `가내댁 ↔ 댁내` → 구성은 비슷하지만 바로 변환하기 어려워 보통
- `가락지빵 ↔ 도넛` → 형태적 연관성이 거의 없어 어려움

`similarity`가 `낮음`인 경우에는 단순 철자만 보고 대응어를 추측하기 어렵다고 판단해
**최소 어려움 수준**으로 보정한다.

## 2. 실제 철자 차이 보정

`similarity`가 같더라도 실제 단어 간 철자 차이에 따라 체감 난이도가 달라질 수 있어
추가 보정을 적용한다. 예를 들어 `보통`으로 분류된 대응어라도 아래 조건에 해당하면
난이도를 낮춘다.

- 두 단어가 4글자 이하
- 실제 철자 차이가 1글자 정도
- 두 단어의 문자 형태 유사도가 매우 높은 경우

따라서 `가달 ↔ 가닥`처럼 한 글자만 다른 짧은 대응어는 `similarity`가 보통이어도
실제 게임에서는 비교적 빠르게 변환할 수 있으므로 쉬움으로 분류될 수 있다. 또한
`similarity`가 높고 두 단어가 거의 동일한 형태인 경우에도 난이도를 추가로 낮춘다.

## 3. 입력해야 하는 대응어의 길이

산성비게임은 제한된 시간 안에 직접 타이핑해야 하므로 **정답의 길이**를 난이도에
반영한다.

| 입력 글자 수 | 점수 |
|---|---:|
| 1~3글자 | 0점 |
| 4글자 | 1점 |
| 5~6글자 | 2점 |
| 7글자 이상 | 3점 |

단어가 길수록 대응어를 알고 있더라도 입력 시간이 증가하므로 난이도가 높아진다.
예를 들어 남북 표현이 서로 비슷하더라도 `가는대말안장버섯 ↔ 긴대안장버섯`처럼
입력해야 하는 단어가 길면 어려움으로 분류될 수 있다.

## 4. 전문어·희귀어 및 생소함

일반 사용자가 평소 접하기 어려운 단어는 추가 난이도를 적용한다. 특히 아래 경우를
고려한다.

- 의학·해부학 관련 표현
- 과학·공학·기술 용어
- 전문 농업·산업 용어
- 희귀 동식물 이름
- 생소한 외래어 및 전문 명칭
- 일반적인 일상어로 의미를 추론하기 어려운 표현

생소함 정도에 따라 다음과 같이 점수를 적용한다.

- 일반적인 표현: 0점
- 다소 생소하거나 전문적인 표현: 1점
- 매우 생소한 전문어·희귀어: 2점

단, 남북 대응어의 철자 형태가 매우 비슷한 경우에는 전문용어라도 서로 변환하기
쉽기 때문에 생소함의 영향을 제한한다.

## 5. 허용 정답 수 보정

각 대응어에는 `north_answers`/`south_answers` 형태로 여러 개의 정답이 허용될 수
있다. 허용 가능한 대응어가 여러 개 존재하고 그중 **4글자 이하의 짧은 답안이 존재하는
경우**, 사용자가 입력할 수 있는 선택지가 늘어난다고 판단해 난이도를 소폭 낮춘다.
즉, 가장 긴 정답만을 기준으로 하지 않고 **실제로 입력 가능한 가장 짧은 허용 정답도
함께 고려**한다.

## 6. 북→남 / 남→북 방향별 난이도 계산

동일한 대응어 쌍이라도 방향에 따라 난이도가 달라질 수 있다. 예를 들어 북한말
`가락지빵` → 남한말 `도넛` 문제와, 남한말 `도넛` → 북한말 `가락지빵` 문제는 같은
대응어 쌍이지만 일반 사용자에게는 `도넛 → 가락지빵` 방향이 더 어려울 가능성이
높다.

따라서 각 대응어에 대해 아래 두 방향을 **각각 별도로 계산**한다.

1. 북한말 → 남한말 입력
2. 남한말 → 북한말 입력

두 방향 중 **난이도 점수가 더 높은 방향을 해당 대응어 쌍의 최종 난이도**로
사용한다. 이를 통해 한쪽 방향에서 지나치게 어려운 문제가 쉬움 단계에 포함되는
것을 방지한다.

## 7. 최종 난이도 결정

각 기준을 합산한 최종 점수에 따라 난이도를 분류한다.

| 최종 점수 | 난이도 |
|---:|---|
| 0~2점 | **쉬움** |
| 3~5점 | **보통** |
| 6점 이상 | **어려움** |

### 쉬움
남북 표현의 형태가 매우 비슷하고 입력해야 하는 단어가 짧아, 표시된 단어를 보고
대응어를 빠르게 연상할 수 있는 경우.

예: `가대기군 ↔ 가대기꾼`, `가동도 ↔ 가동률`

### 보통
남북 표현 사이에 어느 정도 연관성은 있지만 일부 단어를 바꾸거나 기억해야 하며,
입력 길이 또는 생소함이 다소 있는 경우.

예: `가내댁 ↔ 댁내`, `가공덧살 ↔ 가공 여유`

### 어려움
남북 표현의 형태가 크게 다르거나, 전문어·희귀어이거나, 입력해야 하는 단어가 길어
대응어를 미리 알고 있어야 빠르게 입력할 수 있는 경우.

예: `가락지빵 ↔ 도넛`, `가는귀먹기 ↔ 난청`, `가는잎소나무 ↔ 스트로부스잣나무`

## 분류에 사용한 요소 종합

단순한 단어 길이보다는 다음 요소를 중심으로 구성했다.

**남북 대응어 유사도 + 실제 철자 차이 + 입력 길이 + 단어의 생소함·전문성 + 허용 답안 + 양방향 입력 난이도**

이를 통해 실제 게임에서 사용자가 대응어를 **얼마나 빠르게 연상하고 타이핑할 수
있는지**에 가까운 체감 난이도를 반영하도록 구성했다.

## 대응어 최대 길이 4자로 제한 (2026-08-19 추가)

초성게임을 최대 4자로 좁힌 것과 같은 맥락으로, 산성비게임도 화면에 표시되는
단어와 입력해야 하는 대응어가 너무 길면 제한 시간 안에 타이핑하기 어렵다는
판단에 따라 **`north`/`south` 중 더 긴 쪽이 4자를 초과하는 대응어 쌍을 전량
제외**했다(6,841개). 예를 들어 `가는대말안장버섯 ↔ 긴대안장버섯`처럼 어느 한쪽이
길면 반대 방향 문제(`도넛 → 가락지빵`처럼 짧은 쪽에서 긴 쪽을 입력해야 하는
경우와 별개로, 긴 쪽 자체를 입력해야 하는 문제)가 제한 시간 안에 풀기 버거워지는
케이스를 없앤다.

제외 목록은 `acidrain_제외목록_5자이상.csv`에 보관한다. 원본은
`public/data/acidrain_pairs.backup_before_4char_cap.json`으로 백업했다.

| 난이도 | 이전 | 이후 |
|---|---:|---:|
| 쉬움 | 10,832 | 9,747 |
| 보통 | 6,398 | 2,574 |

비중이 함께 줄었다.
