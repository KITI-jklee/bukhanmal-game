# 초성게임 난이도 분류 기준

> 데이터: `public/data/chosung_words.json` (24,288개)
> 최종 갱신: 2026-08-18 (보통→어려움 재점수화 포함)
> 관련 기획서: 북한말_학습게임_상세기획서.md 1-6 (문제 은행 난이도 태깅 기준)

## 분류 원칙

북한말 초성게임의 난이도는 단순히 **단어의 글자 수**만으로 결정하지 않고, 실제 사용자가
**초성과 뜻풀이를 보고 정답을 얼마나 쉽게 추론할 수 있는지**를 중심으로 분류한다.

전체 단어에 대해 아래 기준을 종합하여 난이도 점수를 산정하고, 최종적으로 `쉬움`/`보통`/`어려움`
3단계로 구분한다. (`ChosungWord.difficulty`의 저장값은 이 세 문자열 그대로다 — `src/lib/types.ts`
참고. DB 설계서 문서상의 "하/중/상" 표기는 이 프로젝트에서는 쓰지 않는다.)

## 1. 단어 길이 및 낱말 수 (보조 기준)

단어가 길수록 초성을 기억하고 정답을 입력하기 어려워지는 점을 반영한다. 단, 길이는 난이도를
결정하는 절대 기준이 아니라 보조 기준으로만 쓴다.

- 2~3글자: 가점 없음
- 4~5글자: 난이도 소폭 증가
- 6~7글자: 난이도 증가
- 8글자 이상: 난이도 추가 증가
- 여러 낱말로 이루어진 속담·관용 표현은 전체 길이와 낱말 수에 따라 별도 가점

예를 들어 `가교도`처럼 3글자이더라도 전문적인 단어라면 쉬움으로 분류하지 않으며, 반대로
비교적 긴 단어라도 뜻풀이에서 정답을 쉽게 유추할 수 있다면 난이도가 낮아질 수 있다.

## 2. 단어의 전문성 및 생소함

일반 사용자가 평소 접하기 어려운 전문용어·희귀어는 난이도를 높게 평가한다. 특히 뜻풀이에
아래 전문 분야 특성이 포함된 경우 난이도 점수를 추가한다. 전문적인 특징이 여러 개 동시에
나타날수록 난이도를 더 높게 평가한다.

- 의학·질병·병원체·기생충·세포 등 의료·생물 분야
- 공학·기계·장치·공정·설비 등 기술 분야
- 물리·화학·수학·과학 분야
- 경제학·사회주의 경제·배급·수매 등 특수 경제 용어
- 전문 학문명, 측정 단위, 계수, 체계 등의 전문 개념

## 3. 뜻풀이를 통한 정답 유추 가능성 (가장 중요한 기준)

단어의 일부가 뜻풀이에 직접 등장하거나, 뜻풀이를 통해 단어의 구성 요소를 쉽게 떠올릴 수
있는 경우 난이도를 낮춘다. 반대로 뜻풀이를 읽어도 실제 단어의 형태를 예상하기 어려운
경우 난이도를 높인다.

**예시 (쉬움 쪽)**: `가공선`
> 뜻풀이: `생선을 가공하는 설비를 갖춘 배.`
> → `가공`이라는 단어가 뜻풀이에 직접 등장하고 `선`이 배를 의미하므로 비교적 유추하기 쉬움

**예시 (어려움 쪽)**: `가교도`
> 뜻풀이: `고분자 물질의 다리 결합 정도를 표시하는 척도.`
> → 뜻은 이해할 수 있지만 `가교도`라는 단어 자체를 모르면 정답을 떠올리기 어려움

따라서 **짧은 단어라도 생소하고 유추가 어려우면 보통 또는 어려움으로 분류될 수 있다.**

## 4. 남한 대응 표현(`south_expression`) 존재 여부

`south_expression`에 남한 대응어가 존재하는 경우 단어의 의미를 이해하거나 연상할 가능성이
조금 높다고 판단하여 난이도를 소폭 낮춘다. 단, 게임에서 남한 대응어가 항상 직접 노출되는
것은 아니므로(힌트 1단계에서만 공개 — `chosungConfig.ts`의 `effectiveMaxHintLevel` 참고)
난이도에 미치는 영향은 작게 설정한다.

## 5. 속담·관용구 및 문장형 표현

속담이나 여러 낱말로 구성된 표현은 일반 단어와 별도로 보정한다.

- 여러 낱말로 이루어진 표현
- 전체 글자 수가 긴 표현
- `[ ]` 등 변형 표현이 포함된 경우

위와 같은 표현은 초성의 수가 많고 정확한 문장을 복원해야 하므로 난이도를 추가한다.

## 6. 난이도 보정 (하한 규칙)

일부 단어가 단순 점수 계산으로 지나치게 낮게 분류되는 것을 막기 위한 보정이다.

- 10글자 이상의 긴 단어 → 최소 `어려움`
- 6글자 이상이면서 전문적인 특징이 여러 개 포함된 단어 → 최소 `어려움`
- 8글자 이상이면서 전문적인 특징이 있는 단어 → 최소 `어려움`
- 2~3글자라도 뜻풀이에서 단어를 전혀 유추하기 어렵고 남한 대응어도 없는 경우 → 최소 `보통`

## 최종 난이도 기준

| 난이도 | 기준 |
|---|---|
| **쉬움** | 뜻풀이와 초성을 통해 정답을 비교적 쉽게 유추할 수 있는 단어 |
| **보통** | 단어가 다소 생소하거나 길지만 뜻풀이를 통해 어느 정도 추론 가능한 단어 |
| **어려움** | 전문어·희귀어·긴 표현 등으로 뜻풀이를 봐도 정답을 떠올리기 어려운 단어 |

## 분류 시 제외한 요소

`category` 값은 일부 단어에서 실제 의미와 맞지 않는 분류가 확인되어 난이도 산정에는
사용하지 않았다. 따라서 난이도는 주로 다음 요소를 기반으로 계산한다.

**단어 길이·낱말 수 + 단어의 전문성·생소함 + 뜻풀이를 통한 정답 유추 가능성 + 속담·관용구 여부**

## 8글자 초과 단어 제외 (2026-08-18 추가)

속담·관용구(예: `가난이 소 아들만도[아들보다] 못하다`, 21자)처럼 여러 낱말로 이루어진
문장형 표현은 초성게임(한 단어를 초성으로 맞히는 형식)에 어울리지 않는다는 판단에 따라,
**`word.length > 8`인 문항 2,724개를 전량 제외**했다. 제외 목록은 참고용으로
`chosung_full_제외목록_8자초과.csv`에 별도 보관한다.

같은 정리 과정에서, 같은 (난이도, 초성) 조합 안에 뜻풀이까지 완전히 같은 표기 변이형
3쌍(`갈고리질`/`갈구리질`, `두루뭉시리`/`두리뭉시리`, `오그랑이`/`오그랭이`)이 재분류
이후에도 남아 있던 것을 발견해 각 쌍의 한쪽만 남기고 제외했다.

8자 초과 단어가 유독 `어려움`에 몰려 있었어서(속담·관용구 대부분이 길고 전문 특성
가점도 겹쳐 최고 난이도로 분류됐던 것), 제외 후 `어려움` 비중이 3,633 → 1,458로
크게 줄었다.

## `보통` 재점수화 → `어려움` 승격 (2026-08-18 추가)

4자 이하로 좁히고 나니 `어려움`이 337개(1.4%)뿐이라 지나치게 빈약했다. 그래서
`쉬움`은 그대로 두고, **`보통`으로 태깅된 12,964+2,792=15,756개만 다시 점수화해서
그중 유독 어려운 단어를 `어려움`으로 승격**시켰다.

### 재점수화 기준 (보통 풀 전용)

길이가 2~4자로 좁혀진 상태라 길이만으로는 변별력이 거의 없다. 그래서 1-6의
②③④ 기준을 아래처럼 점수화해서 합산했다:

| 신호 | 가점 | 의미 |
|---|---:|---|
| 길이 4자 | +1 | 2~3자보다 살짝 어려움 |
| 뜻풀이에 전문분야 키워드 포함 (의료·공학·물리화학수학·경제 특수용어·전문 학문명/단위/계수/체계 등) | +2 | 1-6-②의 전문성·생소함 |
| 뜻풀이에 한자 표기 포함 | +1 | 전문어·개념어 신호 |
| 단어의 2글자 이상 조각이 뜻풀이에 등장하지 않음 | +1 | 1-6-③의 "뜻풀이로 단어를 유추하기 어려움" |
| `south_expression`(남한 대응어) 없음 | +1 | 1-6-④ |
| 뜻풀이가 30자 초과로 길고 복잡함 | +1 | 설명 자체의 난해도 |

**합산 점수 ≥ 4점인 단어를 `어려움`으로 승격**했다. 점수 분포를 보면 4점 미만이
대다수(87.9%)이고, 4점 이상이 뚜렷하게 갈라지는 지점이라 이 값을 컷으로 잡았다.

| 점수 | 개수 |
|---:|---:|
| 1 | 11 |
| 2 | 6,538 |
| 3 | 6,415 |
| 4 | 2,469 |
| 5 | 271 |
| 6 | 51 |
| 7 | 1 |

**승격 예시** (점수 높은 순): `물속장욕`(장 속에 물을 넣고 치료하는 목욕), `간위제제`(포유류 간·위로 만든 가루약), `강선기`(총신에 나사 홈을 파는 기계), `길풍뎅이`(곤충 이름) 등 — 전문어·생물 분류명·복합 기술어가 다수.
